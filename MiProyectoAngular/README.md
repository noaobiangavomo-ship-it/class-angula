# Comandos

## Instalación Bootstrap

- ng add @ng-bootstrap/ng-bootstrap 
- npm i bootstrap-icons


## Creación Layout para 404 y 403

- Creamos un layout que tenga un botón para ir a inicio (dashboard) y un texto que diga que está página no puede abrirese. 
- La diferencia entre la 404 y la 403 va a ser el texto "404" y "403". Utilizamos bootstrap, la propiedad <b>display-1<b>
